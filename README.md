# K-Talk Korean v2

A richer Android prototype for foreigners learning practical Korean.

## Included
- Home dashboard
- Daily Korean lesson
- 10 practical expressions
- Categories: Basics, Shopping, Travel, Food, Everyday, Survival, Conversation
- Korean TTS
- XP and progress
- Quiz
- Beginner to Advanced level roadmap
- Product roadmap for AI conversation and speaking score

## Build APK
Open in Android Studio, sync Gradle, then:
Build > Build Bundle(s) / APK(s) > Build APK(s)

APK output:
app/build/outputs/apk/debug/app-debug.apk
